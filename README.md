# VolgoStudent

VolgoStudent web application built with Next.js, Tailwind CSS, TypeScript, and Prisma.

## Getting Started

### Prerequisites
- Node.js (v18+)
- npm

### Installation
`ash
npm install
`

### Database Setup
`ash
npx prisma generate
`

### Running Locally
`ash
npm run dev
`

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
